Preguntas frecuentes

¿Cómo se calcula el 21 % de IVA?

El IVA es la base multiplicada por 0,21, y el total es la base por 1,21. Con una base de 100 €, el IVA es 21 € y el total 121 €.

¿Cómo se calcula de cabeza?

Calcula el 10 % (mueve la coma un lugar), dóblalo y suma el 1 %. Para 250 €: 10 % = 25, doble = 50, 1 % = 2,50, total del IVA = 52,50 €.

¿Cómo se quita el 21 % de un precio con IVA?

Divide entre 1,21. Un precio de 121 € con IVA tiene una base de 100 € y 21 € de IVA.

¿A qué se aplica el 21 %?

Es el tipo general: se aplica a la mayoría de bienes y servicios que no tienen un tipo reducido o superreducido.

Cómo se calcula

Añadir el 21 %: total = base × 1,21. Quitar el 21 %: base = total / 1,21. El IVA es la diferencia entre ambos. El 21 % es el tipo general: se aplica a la mayoría de bienes y servicios que no tienen un tipo reducido. Fuente: Ley 37/1992 del IVA (BOE), art. 90.

# Calculadoras online gratis / Free calculators

Web: **https://puxeuu.github.io/robot-arm-calculators/**

Calculadoras gratuitas, sin registro y con la fórmula explicada (castellano y catalán):
hipoteca, préstamo personal, IVA, porcentajes, descuentos, interés compuesto,
indemnización por despido, IMC, calorías, días entre fechas y edad.

Free robot arm tools (English): joint torque with buoyancy, 2-link inverse kinematics, motor and gear ratio.

Los cálculos están en `calculadoras/calculos.js` y se prueban con `node calculadoras/test.js`.
Si encuentras un error, abre una incidencia en este repositorio.
